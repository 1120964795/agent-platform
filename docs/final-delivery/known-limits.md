# Known Limits And Non-Goals

## Final Non-Goals

- WPS, Word, PPT, or thesis-format office diagnostics.
- Browser history summarization.
- Full-disk automatic scanning.
- Full-source-code embedding.
- Unconfirmed command execution.
- Unconfirmed patch application.
- Background workflow autorun.
- Fully autonomous Agent driving.
- Multi-agent coding.
- Account login.
- Cloud sync.
- Community upload platform.
- Template comments, ratings, ranking, or review backend.
- macOS/Linux support.
- Mobile support.
- Portable zip release.
- Automatic updater.
- Code signing certificate.

## Current Engineering Limits

- Project indexing and companion diagnostics are still narrower than the full V4 product vision.
- Backup/restore has a basic Settings panel entry; detailed per-item conflict comparison is still a follow-up.
- Built-in templates are listed from local resources; importing a built-in JSON template into a saved workflow is a follow-up UI task.
- Security coverage is stronger around workflow packages and backups than around full project indexing, because project indexing is not yet a complete subsystem in this codebase.
